# Security

Do not include credentials, private videos, transcripts, or personal data in a
public issue. Report suspected vulnerabilities through GitHub's private
[security advisory form](https://github.com/tamanhansalia/2pixelshorts/security/advisories/new).
If private reporting is unavailable, open an issue asking for a private contact
without disclosing the vulnerability or affected data.

Include the affected commit/version, platform, reproduction steps using
synthetic data, and the impact. No response-time or support-window guarantee
is currently offered.

Desktop credentials use the native OS store. Editing agents are external local
programs and can send selected transcript/context to their AI provider. The CLI
console executes programs selected by the user. See the
[security review](docs/e2e-security-review.md) for current safeguards and limits.
